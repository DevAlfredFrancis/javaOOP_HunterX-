# Hunter x Hunter Nen Simulation (Java)

A Java-based simulation inspired by the **Hunter x Hunter** anime series, focusing on the Nen power system. This project demonstrates object-oriented programming concepts by modeling Nen users, Nen types, and their unique abilities.

## Activity Overview

This application simulates Nen users and their interactions based on the six Nen categories:

- Enhancement
- Emission
- Manipulation
- Transmutation
- Conjuration
- Specialization

Users can create characters, assign Nen types, and perform abilities according to their Nen affinity.

## Features

- Create and manage Nen users
- Assign Nen categories
- Simulate Nen abilities and actions
- Object-Oriented Design using Java classes and inheritance
- Interactive console-based interface

## Concepts Demonstrated

This project applies several Java programming concepts, including:

- Classes and Objects
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction
- Conditional Statements
- Loops
- User Input Handling

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- Java IDE (IntelliJ IDEA, Eclipse, NetBeans, or VS Code)

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/hxh-nen-simulation.git
```

2. Open the project in your preferred Java IDE.

3. Compile and run the main Java file.
